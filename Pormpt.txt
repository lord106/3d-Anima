Engine Model:

Build a custom, data-driven 3D simulation and video generation engine designed to produce cinematic, timeline-based videos for a specified content niche.

The engine must operate around a persistent 3D environment rather than generating independent scenes for every shot. The environment should be constructed once using procedural geometry, reusable assets, configurable parameters and structured data.

1. Persistent World System

Create a continuous 3D environment containing all the objects, structures, characters, landscapes or other elements required by the selected niche. Every object should have configurable properties, positioning, scale, appearance, animation rules and lifecycle information.

2. Procedural Generation System

Develop a system that generates and distributes objects throughout the environment using structured data, procedural rules, reusable models and configurable parameters. It should support both automatic generation and manually positioned elements.

3. Timeline and State Management System

Every object should be capable of having multiple states throughout the timeline. Support object creation, appearance, growth, movement, transformation, interaction, destruction and removal. The engine must be able to reconstruct the entire environment at any specified timestamp or frame without relying on manually editing every individual scene.

4. Simulation and Animation System

Implement the necessary procedural animations, physics, interactions and environmental changes relevant to the selected niche. The system should support deterministic simulation so that the same inputs consistently produce the same results.

5. Cinematic Camera System

Build an independent camera choreography system with editable camera paths, keyframes, movement curves, tracking targets, zooms, rotations, aerial shots, close-ups and cinematic transitions. Camera movement should be controllable independently from the simulation timeline.

6. Narrative and Timeline Synchronization

Allow a video script or narration track to be imported. Connect narration timestamps to timeline events, simulation states and camera positions. Important narrative moments should trigger their corresponding visual events.

7. Rendering and Export System

Provide automated rendering of selected timelines and camera sequences. Support configurable resolution, frame rate, lighting, materials, shadows and output formats. Allow final footage to be assembled with narration, sound effects, music, subtitles and text overlays.

8. Reusable Architecture

Keep the world generator, object library, simulation rules, timeline controller, camera system, synchronization system and rendering pipeline modular. The objective is to reuse the same engine for multiple videos, episodes and subjects by changing datasets, assets, parameters, events and camera choreography rather than rebuilding the entire environment.

The final product should function as a programmable 3D filmmaking system, not merely a conventional 3D animation project.
