# Channel Strategy: Flywheel, Episode Formats, Economics, Roadmap

## The flywheel (why this niche can win)

Every documentary is a season of the same asset system. One city build (Rome) yields multiple retail formats from one dataset:
- 45-min main documentary ("The Entire Rise and Fall of Rome")
- 15-min spin-offs from the same model ("How Rome's Aqueducts Worked", "The Great Fire of Rome, Second by Second", "What the Forum Looked Like at Every Stage")
- 1-hr "history for sleep" longcut (ambient long-form watch-time lane)
- Shorts cut from single moments

One build stocks ~5 retail formats. No incumbent history-doc channel has this; the user's timelapse pipeline produces the models.

## Economics logic

- 10-min music timelapse monetizes ~10 ad slots; a 40-min narrated documentary does ~10x that with history/education RPMs.
- US adult-male-skewed audience (Kings and Generals demo) pays: 10K+ monthly Patrons on that channel.
- Big-doc channels tolerate low cadence: Majestic uploads 0.2x/week and still prints a 423K median.
- Strategy note: seed with one tentpole episode, then support; one city = one build = 3 videos cadence rather than weekly uploads.

## Distribution reality

Code-visual content almost never trends globally; it wins via search + recommendation longevity. Judge niches by upload-date + view curves, not trend spotlights. Emotionally-curated titles ("The ENTIRE History of...", "Rise and Fall of...") double as search queries promising completeness in one watch.

## Funding/positioning signals

- "Made without AI" is now a thumbnail-label strategy (MetaBallStudios brands it; CITY 3D TIMELAPSE and CityEons state it) - audiences reward code-made over gen-AI in this market.
- Frontier wave: agents writing Blender code (Gemini 4 Argon demo 12.56M views Oct 2026). Batch-automation of this niche is forming; diversifying format/theme beyond music-only timelapse is time-sensitive.

## Locked roadmap decisions

1. Niche locked: narrated 3D "Rise and Fall of X" documentary using custom engine.
2. Immediate next step: plan the engine build in layers - (a) engine first, (b) one pilot city, (c) then the flywheel formats.
3. Engine hard-problem named: Stage 2 time-sliced dataset from historical maps; plan splits it into easy-start vs deep so the pilot city can ship while deep mode matures.
4. Pilot cities shortlist: Rome, Constantinople, Detroit (with Tenochtitlan, Carthage, Baghdad, Alexandria, Pripyat as the following queue).
5. Format mix per city: main doc + Shorts + optional sleep-longcut; camera choreography authored per episode via keyframes; narration synced audio-first.

- whether first tentpole is Constantinople (best match-cut story: walls built in rise, breach in fall) or Rome (biggest search demand).
